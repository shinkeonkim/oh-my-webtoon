# 5. 디자인 시스템

화면마다 따로 꾸미지 않고 **공통 컴포넌트만 조합**한다. 살아 있는 목록은 `/ui` (스타일 가이드 화면).

```
templates/_ui.html      매크로 (모양의 "API")      {% import "_ui.html" as ui %}
static/style.css        1 토큰 → 2 기본 → 3 컴포넌트 → 4 조각 → 5 화면
```

## 규칙

1. 색·간격·모서리·글자 크기는 `style.css` 맨 위 **토큰**(`--accent`, `--space-3`, `--radius` …)으로만 쓴다. 숫자 색을 새로 쓰지 않는다.
2. 화면 템플릿에 `style="..."` 를 쓰지 않는다. 필요한 모양이 없으면 컴포넌트(또는 간격 유틸 `mt-3`, `mb-4` …)를 추가한다.
3. 새 컴포넌트를 만들면 `_ui.html` 매크로 + `style.css` 3절 + `/ui` 예시를 같이 추가한다.
4. 다크 모드는 토큰만 바꿔서 처리한다 (`prefers-color-scheme: dark`).

## 컴포넌트

| 매크로 | 쓰임 |
|---|---|
| `button(label, variant, size, href, …)` | primary / secondary / ghost / danger, md / sm |
| `icon_button(name, label)` | 아이콘만 (편집 등) |
| `badge(text, tone, icon_name)` | 무료 화수(accent·solid·warn), 기간 한정(promo), 평점 |
| `chip(label, on)` | 켜고 끄는 상태 (봤음·보는 중 …) |
| `field(label, hint)` + `.input` / `select(...)` | 폼 칸. 셀렉트는 브라우저 기본 모양 대신 같은 높이·테두리 |
| `tabs(items)` | 필터 줄 (상태·별점) — 넘치면 가로 스크롤 |
| `stars(score)` / `star_input(no, score)` | 별점 표시 / 입력 |
| `progress(percent)` | 진행 막대 (이어 보기) |
| `bar(label, ratio, value)` | 가로 막대 한 줄 (취향 통계) |
| `empty()`, `page_header()` | 빈 상태, 화면 제목 |

메뉴(`base.html`): 섹션 셋(추천 · 평가 · 소식)을 한 번 정의해 세 곳에 그린다 — 위 메뉴(마우스를 올리면 하위 메뉴),
모바일 아래 탭바(+ 내 정보), 화면 위 하위 메뉴 탭(`.subnav`, 하위 화면에 있을 때만). 내 메뉴(설정·로그아웃)는 `<details>`.
새 화면은 섹션의 하위 목록에 한 줄 더하면 세 곳에 다 나온다.

조각: `_card.html`(작품 카드 — `dismissable=true` 면 × 로 '관심 없음' 후 되돌리기), `_review.html`(평가 위젯 — 본 화수가 있으면
남은 화수·무료 화수), `_review_form.html`(세부 평가), `_quick.html`(빠른 평가 한 장).

## 별점 (0~10점 = 별 0~5개, 반 개 단위)

DB 에는 0~10 정수로 저장하고, 화면은 별 반 개 = 1점으로 보여 준다.

- 별 하나 = 왼쪽 반 버튼 + 오른쪽 반 버튼. 각 버튼은 너비 10px 로 별 SVG 의 절반만 보이게 자른다(오른쪽 반은 `margin-left: -10px`).
- 버튼 순서는 DOM 에서 10→1, 화면에서는 `flex-direction: row-reverse` 로 1→10.
  그래서 CSS `:hover ~` (뒤 형제 = 화면에서 왼쪽) 만으로 "마우스를 올린 곳까지 미리보기"가 된다. JS 가 없다.
- 같은 값을 다시 누르면 지운다(toggle). 별 0개(0점)는 앞의 작은 `0` 버튼.

## 캐시

CSS/JS 주소에 내용 해시(`?v=…`)를 붙인다 (`app.static_version`). 파일이 바뀌면 주소가 바뀌어서
브라우저가 옛 스타일을 계속 쓰는 일이 없다.
