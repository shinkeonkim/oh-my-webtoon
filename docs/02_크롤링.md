# 2. 크롤링

## 네이버 시리즈 페이지 구조 (2026-10 확인)

| 페이지 | 경로 | robots.txt | 쓰임 |
|---|---|---|---|
| 장르/전체 목록 | `/comic/categoryProductList.series` | **Disallow** | 쓰지 않는다 |
| 코믹스 홈 | `/comic/home.series` | 허용 | 시드 |
| TOP100 | `/comic/top100List.series?rankingTypeCode=DAILY&categoryCode=88&page=2` | 허용 | 시드 (3 랭킹 × 6 분류 × 5페이지) |
| 매일 10시 무료 | `/comic/specialFreeList.series?page=N` | 허용 | 시드 + 기간 한정 무료 정보 |
| 작품 상세 | `/comic/detail.series?productNo=N` | 허용 | 작품 데이터 + 연관 작품 링크 |

목록이 막혀 있어서 **시드 → 상세 → 상세 안의 링크(작가의 다른 작품, 이 장르 인기작, TOP10)** 순서로 넓혀 가는
BFS 를 쓴다. 시드만으로도 약 1,200개 작품 번호가 모이고, 상세 페이지마다 20개 남짓 링크가 더 나온다.

## 상세 페이지에서 뽑는 것

`crawler/parser.py` 맨 위 docstring 에 HTML 조각과 함께 정리돼 있다. 핵심만:

- 무료 정보: `<div class="area_text_information"><strong>3화</strong> 무료</div>`
  - `N화 무료` / `N권 무료`(단행본) / `전화 무료` / `전권 무료` / 표시 없음(=0)
- 총 회차: `<h5 class="end_total_episode">총 <strong>349</strong>화</h5>`
- 해시태그: `<meta name="description" content="349 화 연재중, #COMIC, #무협, #먼치킨, ... 줄거리: ...">`
- 19금 작품은 로그인 페이지(`nid.naver.com`)로 리다이렉트 → `skipped` 로 표시하고 건너뜀
- 기간 한정 무료("33화 무료 50일 남음")는 상세 페이지엔 기간이 안 나와서 무료관 목록에서 따로 모은다(`free_promos`)

## 큐 상태

```
pending ──fetch 성공──▶ done ──(7일 지나면 재수집)──▶ pending
   │
   ├──로그인 필요──▶ skipped
   └──오류──▶ failed (3번까지 재시도)
```

## 매너

- 요청 간격 1.5초 (`CRAWL_DELAY_SECONDS`) — 한 번 실행(300개)에 약 8분
- 5xx/네트워크 오류는 지수 백오프로 최대 3번
- User-Agent 에 이 서비스 주소를 넣어 누가 요청하는지 알 수 있게

## 네이버가 마크업을 바꾸면

1. `uv run my-webtoon import <productNo>` 로 하나 가져와 보고 어떤 필드가 비는지 확인
2. 실제 페이지를 열어 바뀐 클래스명을 `parser.py` 에 반영
3. `tests/fixtures/detail_sample.html` 도 같은 구조로 고치고 `uv run pytest tests/test_parser.py`
