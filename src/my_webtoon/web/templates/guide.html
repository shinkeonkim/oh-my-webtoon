시작하기

my-webtoon 은 내가 남긴 평가만으로 작품을 추천해요. 다른 사람의 평가는 섞지 않아요. 그래서 처음엔 추천이 비어 있고, 평가가 쌓일수록 정확해져요.

  1. 처음 로그인하면 빠른 평가로 바로 안내해요. 장르별로 많이 본 대표작을 하나씩 보여 주니, 본 작품엔 별점, 안 본 작품은 '보류'로 넘기세요. 별점 {{ onboarding_target }}개가 모이면 추천을 볼 수 있어요.
  2. 추천 화면에 내 취향에 맞는 작품이 순서대로 나와요.
  3. 마음에 드는 작품을 눌러 네이버 시리즈에서 보기로 바로 이동해요. 다 보고 나면 별점을 남겨 주세요 — 다음 추천이 더 좋아져요.

추천 화면

{{ shot('recs', '추천 화면: 내 취향에 맞는 작품 카드가 순위대로 나열돼 있다') }}

로그인하면 처음 보는 화면이에요. 위에서부터 최종 점수가 높은 순이고, 끝까지 내리면 다음 작품들이 계속 이어져요.

  • 안 본 것만 / 본 것 포함 / 본 것만 — 기본은 아직 평가하지 않은 작품만. 다시 볼 작품을 찾을 땐 '본 것 포함'.
  • 점수 공식 조정 — 무료 회차·총 회차·네이버 평점을 얼마나 반영할지, 유료 위주 작품을 뒤로 보낼지, 얼마나 다양하게 섞을지 직접 바꿔 볼 수 있어요.
  • 소식 · 빠른 평가 바로가기 — 최근 무료가 늘어난 작품 수가 보이고, 누르면 소식 화면으로 가요.

최종 점수 = 취향 유사도 × 보정(무료 회차 · 총 회차 · 네이버 평점)

취향 유사도는 내가 좋아한 작품들과 줄거리·장르·태그·작가가 얼마나 닮았는지예요. 위쪽이 비슷한 작품으로만 채워지지 않도록 조금씩 섞고, 무료 3화 이하인 '유료 위주' 작품은 점수와 상관없이 뒤로 보내요.

취향 반영: 10점일수록 강하게 끌어당기고, 4점은 중립, 그보다 낮으면 비슷한 작품을 조금 밀어내요. 오래된 평가는 조금씩 약해져요(그래도 절반 아래로는 안 내려가요).

평가한 작품은 내 평가까지 반영한 추천도예요 — 별점을 올리면 오르고 내리면 내려가요. 상자 아래에 평가하기 전의 예측값('평가 전 예측')도 함께 보여 줘서, 추천기가 미리 맞혔는지 볼 수 있어요. 아래쪽에는 이 작품과 비슷한 작품들이 나와요.

빠른 평가

{{ shot('quick', '빠른 평가 카드: 별점과 저장하고 다음, 보류 넘기기 버튼', marks=[(1, 3, 60), (2, 3, 70), (3, 3, 82)], narrow=True) }}

한 장씩 넘기며 평가 수를 빠르게 늘리는 화면이에요. 할 수 있는 건 둘뿐이에요.

  1. 별점을 고르고
  2. 저장하고 다음 — 상태는 '봤음'으로 저장돼요.
  3. 보류 · 넘기기 — 안 봤거나 애매할 때. 취향에 반영하지 않고 {{ skip_days }}일 동안 다시 묻지 않아요.

많이 본 작품, 내 취향과 가까운 작품부터 물어봐요. 한 장르로만 좁아지지 않도록 {{ explore_every }}장마다 한 번은 내가 덜 평가한 장르의 작품이 섞여 나와요 ({{ ui.badge('다른 취향도 섞어 볼게요', 'promo', icon_name='sparkle') }} 표시).

실수로 넘겼다면 위쪽의 '되돌리기'를 누르세요. 상태·본 화수는 작품 화면에서 남겨요.

찾아서 평가

{{ shot('rate', '찾아서 평가 화면: 검색칸과 장르·정렬·무료·연재 필터, 상태별 탭, 작품 카드') }}
  • 제목·작가 검색칸에도 자동완성이 떠요. Enter 를 누르면 고른 필터와 함께 목록으로 보여 줘요.
  • 장르 · 정렬 · 무료 회차 · 연재/완결로 거르고, 아래 탭으로 내 평가 상태별로 볼 수 있어요.
  • 찾는 작품이 없으면 아직 수집하지 않은 작품이에요. '네이버 시리즈 링크로 가져오기'에 작품 주소를 붙여 넣으면 바로 추가돼요.
  • 시리즈 내 서재에서 가져오기 — 네이버 시리즈에서 본 작품을 한 번에 가져올 수 있어요 (데모 계정은 막혀 있어요).

검색

{{ shot('search', '위 메뉴 검색창에 회귀를 입력하자 작품 목록이 뜬 모습', marks=[(1, 3, 13), (2, 97.5, 15), (3, 3, 96)], narrow=True) }}

모든 화면 위쪽에 검색창이 있어요. 제목이나 작가를 치는 동안 작품이 바로 떠요.

  1. 맞는 부분이 초록색으로 표시돼요. 띄어쓰기는 무시해요 — '나혼자' 로도 '나 혼자만 레벨업' 을 찾아요.
  2. 로그인했다면 추천도도 같이 보여요. 누르면 작품 화면으로 바로 가요.
  3. 전체 보기 (또는 Enter) — 검색 결과 전체 목록.

어느 화면에서든 / 를 누르면 검색창으로 가요. ↓ ↑ 로 고르고 Enter 로 열고, Esc 로 닫아요.

소식

{{ shot('news', '소식 화면: 이어 보기 카드와 무료가 늘어난 작품 목록') }}

작품 정보는 {{ settings.crawl_interval_hours | int }}시간마다 다시 수집해요. 그 사이 바뀐 것 중 반가운 소식만 최근 {{ news_days }}일치를 모아 보여 줘요.

  • 이어 보기 — '보는 중'인 작품. 본 화수를 남기면 남은 회차와 무료로 더 볼 수 있는 회차를 알려 줘요. '+1화 봤어요'로 바로 올려요.
  • 바뀐 작품 — 무료 회차가 늘었거나 전부 무료가 됨, 새 회차, 완결, 기간 한정 무료(남은 기간 표시).
  • 내가 보는 중·보고 싶음·봤음인 작품 소식이 위로, 관심 없음·하차·낮은 점수를 준 작품 소식은 빠져요.
